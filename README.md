# bentocakes_irk — лендинг

Одностраничный сайт для кондитера Сони ([@bentocakes_irk](https://www.instagram.com/bentocakes_irk/)): бенто-торты, торты на заказ, стаканчики, трайфлы, капкейки, тортик в кружке и мастер-классы в Иркутске.

## Состав

```
index.html            — страница (семантика, Open Graph, JSON-LD: Bakery, Person, FAQPage)
css/style.css         — стили (адаптив 320–1920 px, iOS safe-area)
js/main.js            — меню-бургер, конструктор надписи, вкусы, табы цен, слайдер отзывов, лайтбокс, ленивая карта
img/                  — фото WebP (640/1200) + JPEG-фолбэк, иконки, og.jpg
video/                — видео H.264 без звука + постеры
robots.txt            — индексация + разрешения для AI-поисковиков (GEO)
sitemap.xml           — карта сайта с изображениями
llms.txt              — факты о бизнесе для нейросетей (GEO)
site.webmanifest      — PWA-манифест
.htaccess             — сжатие и кеш для Apache (по желанию)
favicon.svg
```

## Блоки

1. Первый экран + конструктор надписи (ввод текста → превью на тортике, выбор цвета крема, автоматический расчёт цены по числу слов, кнопка «Заказать» копирует текст заказа и открывает Telegram)
2. Что в коробочке (комплект к каждому тортику)
3. Вкусы — переключатель «начинка × бисквит» с реальными разрезами
4. Меню и цены — вкладки: бенто, торты, стаканчики, трайфлы, капкейки, тортик в кружке
5. Работы — галерея фото и видео с лайтбоксом
6. Мастер-классы
7. О Соне
8. Как заказать + условия
9. Отзывы — слайдер (свайп, стрелки, точки, автопрокрутка)
10. FAQ (размечен как FAQPage)
11. Контакты + Яндекс.Карта (Маяковского 65, 1-й подъезд)

## Перед публикацией

- **Домен.** Заменить `https://bentocakes-irk.ru/` на реальный во всех файлах: `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `llms.txt`.
- **Отзывы.** Тексты в блоке «Отзывы» — образцы для макета. Перед запуском замените их на реальные отзывы клиентов (скрины из директа/ВК) — так честнее и лучше конвертит.
- **Описания вкусов** в `js/main.js` (объект `FLAV`) написаны по фото разрезов — пусть Соня проверит формулировки.
- После запуска добавить сайт в Яндекс.Вебмастер и Google Search Console, отправить `sitemap.xml`; создать/обновить карточку в Яндекс.Бизнесе и 2ГИС с тем же адресом и ссылкой на сайт.
- Сайт статический: подходит любой хостинг (Timeweb, Beget, Netlify, GitHub Pages). Просто загрузить содержимое папки в корень.

## Технически

- Кроссбраузерно: Safari iOS 14+, Chrome/Android 8+, Firefox, Edge, Яндекс.Браузер. `<picture>` с JPEG-фолбэком, `playsinline` для видео на iPhone, `100dvh` с фолбэком, safe-area для «чёлки».
- Производительность: изображения в WebP двух размеров с `srcset`, `loading="lazy"`; видео грузятся и играют только в зоне видимости; карта подгружается при подлёте к блоку.
- Доступность: семантические теги, `aria` у меню, табов, слайдера и радиокнопок, управление с клавиатуры, `prefers-reduced-motion`.
